# 💰 ExpenseFlow - Budget Tracker App

A modern, visually stunning expense tracking application built with vanilla HTML, CSS, and JavaScript.

![ExpenseFlow Dashboard](https://img.shields.io/badge/Version-1.0.0-blue) ![License](https://img.shields.io/badge/License-MIT-green)

## ✨ Features

- 📊 **Dashboard** - Beautiful overview with summary cards
- 💳 **Expense Tracking** - Add expenses with categories
- 💵 **Income Tracking** - Track your income sources
- 📈 **Interactive Charts** - Pie chart for categories, Line chart for trends
- 🎯 **Budget Goals** - Set and track budget limits per category
- 💡 **Key Insights** - AI-powered spending analysis
- 💾 **Local Storage** - Data persists in your browser
- 🇮🇳 **Indian Rupees** - Currency formatted in INR (₹)

## 🚀 Getting Started

### Prerequisites

- Node.js (v16 or higher)
- npm

### Installation

1. Clone or download the project

2. Install dependencies:
```bash
npm install
```

3. Start the development server:
```bash
npm run dev
```

4. Open your browser at `http://localhost:5173`

## 📱 How to Use

1. **Add Income**: Click the `+` button → Select "Income" → Enter amount & description
2. **Add Expense**: Click the `+` button → Select "Expense" → Choose category → Enter details
3. **View All Transactions**: Click "Transactions" in sidebar or "View All" link
4. **Track Budgets**: Monitor your spending against budget goals
5. **See Insights**: Check the Key Insights section for spending analysis
